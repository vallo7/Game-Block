# Ink Blast

Prototype de jeu mobile puzzle créé avec :
- HTML
- JavaScript
- Canvas
- Capacitor
- GitHub Actions

## Objectif
Créer une version Android du jeu Ink Blast depuis GitHub.

## Structure
- `www/index.html` : prototype jouable
- `capacitor.config.json` : configuration Capacitor
- `.github/workflows/build-apk.yml` : génération automatique de l'APK

## Build
L'APK est généré automatiquement dans l'onglet **Actions** de GitHub.
